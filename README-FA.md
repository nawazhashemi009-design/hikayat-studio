# حکایت استودیو — راهنمای نصب

## ساده‌ترین راه: آنلاین کردن (بدون ترمینال)
1. در github.com حساب بسازید و یک مخزن **Private** جدید بسازید. محتویات همین پوشه را با «Upload files» آپلود کنید (کلید را هرگز داخل فایل‌ها ننویسید).
2. در render.com با حساب GitHub وارد شوید → New → Web Service → همان مخزن را انتخاب کنید.
3. Runtime: Node ، Build Command: خالی (یا `npm install`) ، Start Command: `npm start`
4. در بخش Environment یک متغیر بسازید: نام `GEMINI_API_KEY` و مقدار = کلید شما از https://aistudio.google.com/apikey
5. بعد از Deploy، آدرس سایت را در Chrome اندروید باز کنید → منوی سه‌نقطه → «Add to Home screen / نصب برنامه».

اگر کلید را در Render تنظیم نکردید، می‌توانید در صفحهٔ «کلید Gemini» داخل برنامه واردش کنید (فقط روی همان گوشی ذخیره می‌شود).

## اجرا روی کامپیوتر
Node.js 18+ نصب کنید، در پوشه `npm start` بزنید و http://localhost:3000 را باز کنید.
